# My design preferences

The owner's general design taste, across all projects. Detailed entries live
in the topic files. This file lists the ones that matter most and the ones
still waiting for evidence.

Last updated: <YYYY-MM-DD>

## How to read this

Each preference has an ID (`P-001`), a strength (`strong`, `moderate`,
`tentative`), and evidence. A strong preference is a default the design
director must follow unless the client's brief requires otherwise. A
tentative one is a hint.

Preferences describe taste, not a house style. Apply them to fit each client.
Two projects that follow these preferences should still look different.
